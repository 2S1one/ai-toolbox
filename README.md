# AI Toolbox

A collection of AI-powered tools for security research and operational workflows.

## Projects

| Project | Description |
|---|---|
| [reddit-monitor](./reddit-monitor/) | Monitors Reddit for security posts, enables semantic search, and delivers GPT-filtered Telegram notifications |

## Philosophy

Each tool in this repository is built to solve a specific operational problem — not to demonstrate technology. The focus is on reliability, low noise, and practical value in a security context.
